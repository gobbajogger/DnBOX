# Stock DNR2 producer fit

Both stock application and FWSC hashes agree between the Integration and Remote records. Use [the existing stock artifacts](../qualification-0130/firmware-native-results.json) for unchanged configurations. The five-zone offline slot readback and the matching 32 Remote proposals also retain their original scope.

The existing [production dispatcher probe](https://github.com/gobbajogger/DnBOX-nightly/blob/995d5493386fad889ca8106758567c9fe80a47d5/tests/product-remote/stock-editor-probe.c) reproduced stock INFO at 25 bytes and DNR2 HELLO at zero. The [editor](https://github.com/gobbajogger/DnBOX/blob/e29c99ec2cc610e5af3de575e85771f666b239f4/firmware/src/app/editor.c#L1105) leaves the non-editor frame pending. The [OTA handler](https://github.com/gobbajogger/DnBOX/blob/e29c99ec2cc610e5af3de575e85771f666b239f4/firmware/src/ota.c#L161) consumes it and rejects its framing. The [archived browser replay](https://github.com/gobbajogger/DnBOX-nightly/blob/995d5493386fad889ca8106758567c9fe80a47d5/evidence/remote-resume-0130/engine-protocol/README.md) exercised guarded Apply and Undo against real engine code using a test-only catalog.

The cached Elite objects relinked to the original four loadable sections byte for byte. The existing receive/decode/reply codec alone adds 576 B and leaves 652 B of XIP, 372 B below the 1,024 B reserve. Adding the existing core overflows XIP by 928 B before dispatcher and catalog work. The existing core needs at least 1,952 B reclaimed to meet the reserve, with additional space for the dispatcher, catalog adapter and final image marker. These measurements apply to the current stock inputs and do not rule out a smaller implementation. The experiment did not link a production endpoint, expose a catalog, or touch the updater or maintenance guards.

Reproduce with the exact cached Elite object set, the pinned JieLi compiler and the unchanged reference sources listed in `receipt.json`. Compile `remote_core.c` and `remote_wire.c` separately with `clang -target pi32v2 -mcpu=r3 -mfprev1 -ffp-contract=off -Oz -flto -ffunction-sections -fdata-sections -fno-builtin -idirafter TOOLCHAIN/pi32v2/include -c SOURCE -o OUT/NAME-lto.o`. Run `python3 -B relink.py OUT FIRMWARE TOOLCHAIN`. The relink script verifies the stock application digest and the loadable sections before measuring either probe.

Producer acceptance requires an exact stock-derived image with memory reserves, a stable admitted source catalog, mutation/revision and lease checks, and the real protocol's HELLO, addressed read, acknowledged Apply, fresh read and guarded Undo witnessed through production dispatch. Keep the Remote consumer fail-closed until those exist. Do not repeat the full gate before the final combined candidate.
