# Synth One delay input averaging ablation
Host only; no firmware or device changes. Original renderer SHA-256 20628c91a910bc99f6ccff7ce76798985e4e1b3c373fe9f14faabc2ff8bb2f56. Existing 2,152-byte history, F16 codec, cadence, comb coefficients, path topology and interpolation all unchanged. Only retain a symmetric center sub-window of each averaging group and divide by the exact retained count, preserving DC response and window center. Compare the full original six WAV previews using the existing fixed calibration and sample timing, and compare isolated candidate echoes (tap immediately after history reconstruction, before wet scaling and room).

`RESULTS.txt` records all six programs. Every dry result is byte-identical across variants. Quarter-window case moves Pad's last second closer in level (−6.299 to −1.120 dB) but its waveform residual worsens (+1.357 to +2.826 dB), and Sahara/Atmostrings get louder than the originals. The 500–1000 Hz Pad right echo band only recovers 4.684 dB relative to the existing compact stem and remains about 32 dB below the same-engine full-rate causal proxy. No upgrade recommended. A shorter window cannot raise the 490 Hz history Nyquist at d45; e.g. a 3,000 Hz tone aliases to 60 Hz in the stored cells, and a shorter averaging window significantly raises this unwanted response. The tone example describes input sampling, not a synth render.

Reproduce by copying the source/script files here into a standalone directory, copying the existing path bench's `firmware` and `build` into it, linking `experiments` to the absolute `ab-latest-headless/experiments` and `baseline` to the absolute `s1-controlled-ab/baseline`, then running `bash run.sh /absolute/workspace` and `python scores.py`. The checkout, original WAVs, FDATA, intermediates and executable aren't included. No claim of target code size, target timing or warm parameter parity.
