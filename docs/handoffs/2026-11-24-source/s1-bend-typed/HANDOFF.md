# Synth One original Pitch Down/Up, typed owner carry
Host-only scratch delta atop exact b71f366f, combined ID137 fixture, MOD receiver and UI, and installer tuple binding. Use `sh replay.sh ../controls-init-only/source-mod-wheels` from this directory. One copy is reused across new and unchanged predecessor test arms, then removed. Do not enable this host witness for native or convert old media in this patch.

The approved shared typed owner rows keep ID137 [2] and MOD route [3] byte-identical. [4]=PB Down, [5]=PB Up, 0 means original default position 12; 1..24 encode remaining positions excluding 12. Down is position minus 24, Up is position. Each original endpoint 0, ±24 and every integer interior detent is represented exactly; 25+ reject; [6..63] stay canonical zero. Old and non-Init records do not expose the page or use a new pitch law. The old receiver retains exact legacy ±2. Existing typed zero is original Init ±12. Types have not been claimed for product format. Installer solver confirmed no offset conflict; its STREAM16 virtual generation binding hashes all Sound bytes.

A Synth One typed WHEELS page has the two physical encoders only. The independent MOD selector stays exactly where it was. Current revision + admission + note-lock + render commit paths publish the typed pair; cold adoption reconstructs both independently. Undo preflights candidates, rechecks under audio hold, and applies the actual restored pair. Read-only recovery refuses edits/Undo/save; previous generation stays readable. A PB edit while a physical or MIDI note is held updates its current raw wheel bend directly without another gesture. No new note-lock field: during V3 playback, PB ranges remain live owner performance configuration, while existing MOD freeze/playback/restore continues. PB edits are refused while the note lock is active.

Measures host UI path, render/mailbox state and actual ADC/MIDI ingress, not physical-unit or native fit/performance; no banks/release writes. The older same test format is not promised forward-compatible in place. The unchanged legacy source rejects the new actual writer's native/portable media, BT and ED_PROJECT without writes. Hardware flash failure model, new product schema assignment, native fit/timing and owner-approved product layout are out of scope.
