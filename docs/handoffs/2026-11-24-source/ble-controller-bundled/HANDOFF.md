# Bundled BLE controller cold audit (historical published packages)

Existing locally materialized release FWSC files were consumed read-only. No production build, blob creation, package writes, Git, hardware or distribution. Duplicate-hash inventory selected 93 unique local FWSCs: 70 empty BLE sections and 23 valid embedded controllers by add_ctl.py. The reviewed common artifact is 61,552 B, SHA256 a334208b51f62bc7231ebb76a6de0dfa260033d7f7316e5b92053c540bc1d984, header v2/ABI2, CRC32 564a8f55, in both 94197fc8 owner-hardware-tested packages and both published 73749f55 test packages. The scripts validate package and controller bytes, identity, model and header bounds (including CRC, IRQ ownership, and erased trailing area) in memory, without exporting controller bytes.

Runner is local fm1-live-ba83317a fdd1504d8801a69a95c24226357f4b202bbaa345565c80a1bbf861f69a287017, 360MHz, strict no skip, a disposable initially nonexistent virtual flash per shot. Both historical bundled package pairs boot and then make sequenced audio from virtual physical pads and PLAY at 2200 ms. Unique ABI2 mailbox in RAM, stage 7/state 2/error 0 at both 2500 and 3500 ms, with increasing polls (ABI2 word 15 heartbeat). Package protected prefix unchanged. 0.0.26 early monitor reported one late; absence of work/ directory means no LCD file for those shots, but post-shot RAM and audible PCM are valid. The 73749 pair includes work/ and LCD file. Numeric receipts separate exact package, controller, RAM, PCM and scene identities. No BLE MIDI/RF was stimulated; this verifies simultaneous controller execution, heartbeat, and sequenced audio, not wireless transport or the heavy gate.

These are not recomposed 8eff93af images: those specific artifacts remain controller-empty and their audible PCM proof is separately scoped. Current full-controls stock app did not link, so historical positives do not qualify current release firmware.

Reproduce from workspace root with PYTHONPATH=exact-ble-cold-fw/tools python perf-final-proof/ble-controller-bundled/dnble-pub27-check.py SCRATCH, where SCRATCH is an existing empty absolute directory. Use only with reserved serial emulator slot; script holds the lock throughout.
