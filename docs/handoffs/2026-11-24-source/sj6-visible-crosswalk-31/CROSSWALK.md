## Do not turn existing aliases or ambiguities into missing controls

- Current AMP owner retains topology. ENV has four compiled AMP sliders and independently Filter ADSR with AMP→FILTER (116). It does not prove visible independent AMP2 sliders there. Build 9 IDs 36–39, 119–122 and AMP1→AMP2 link 115 require distinct runtime proof; shared DnBOX AMP is not eight original controls. Later direction GIFs are not original runtime evidence.
- **The pinned 31 has a fixture undercount candidate, not missing DSP:** its mapped_juno switch omits SJ6_A_REFERENCE although exact source routes OSCILLATOR K4 to original 206 and retains typed raw paths. Prior full-control-a-reference/HANDOFF.md proved 200+400u Hz and actual physical changes with save/reload and peer isolation. Original Tunings storyboard proves a tuning panel but not a dedicated A-ref outlet from this parse. Leave the published 31 intact, report the independent existing binding, and refresh the inventory fixture rather than scheduling a duplicate implementation.
- JNO four fine/PWM slots have explicit initial hidden-field tags; a compiled widget is not a guarantee of default visibility or how it opens. Already mapped in DnBOX. Three source range toggles represent one role 86; Main output knob and ENV slider share 0; LFO2 RATE appears twice but is 96 once.
- Main Distortion amount/switch widgets are genuine, despite corresponding metadata 111/112 being outside the main preset apply order; their exact route is unresolved. FX Crush has explicit toggle/amount (107/108 strong), but metadata does not prove distinct editable bitrate/mix. Bonus limiter thresholds/headroom/gain/release are real knobs; never assign release to metadata Attack ID20 or assume exact limiter aliases from labels.
- Typed outlet evidence comes from archived objects; it does not prove runtime reachability or component execution. Catalog joins above are same-name identity crosswalks, not live callback disassembly unless separately sourced. Preset occurrence counts are not proof of active or audible values. Exclude reserved 207 and unproven storage fields such as receiver base words as separate visible dials.
