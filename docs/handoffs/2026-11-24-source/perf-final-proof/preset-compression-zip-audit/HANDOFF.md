## Foreground cost evidence, not a native decoder claim

DNP host full J6 decode materializes 11,514 exact sorted dictionary words = **46,056 B** for raw words alone, and 3,055 Huffman symbols over 174 fields, largest table 113. A bounded alternative needs parsing field table starts and limited decode, not copying Python's buffers. One dictionary page is up to 256 words =1,024 B if materialized, existing rank checkpoint can instead stream it with fewer bytes at greater cost, as-yet unqualified. 24-bit offsets for direct per-field table lookup would add another 522 persistent bytes (954 for 318 current combined fields); these are not in actual DNP1. Joint eager words alone require 69,712 B. Worst frame/time is not measured. Header limits and a full validated transactional decoder remain absent.
