# Synth One product-control coverage

**No.** The pinned stock Elite/Pro source exposes **14 directly editable Synth One sound controls**. DnBOX also exposes a shared ARPEGGIATOR and ARP SEQ, a sound/preset selector and performance input. Compact preset playback reaches a broader parameter set. There is no authenticated denominator for the complete original iOS control surface.

- Original AudioKitSynthOne `6466a3715c96b7ecf1dd255a218cbd571408a314`, tree `2a36703ec69a24e6669942f7492c315233741cb2`. The source check verifies 89 individually listed closure file hashes and 10 original Swift source blobs from the separate tuning fixture. The original enum contains **150 IDs**, including **48 sequencer step fields** (16 pitch offsets, 16 octave boosts, 16 on/off). It labels 18/filterMix and 33/bitCrushDepth unused and 145/oscBandlimitIndexOverride deprecated. The generated map selects 46 smoothing entries. Neither set measures accessible controls. - The app fixtures authenticate selected tuning, pitch-bend, sustain, and mod-wheel callbacks plus preset load/storage sources. They supply no complete editor/controller or display inventory. - **FILTER LINK is a separately tested patch.** It uses DnBOX ID 255 and the FILTER row's fourth knob to use AMP ADSR for the filter while preserving the independent FILTER ADSR. Both dry and compact host fixtures passed 40 checks covering both owners, actual detents, changed PCM, project reload, and bit-exact restoration on unlink. Compact changed 8,014 of 8,192 samples per owner. The patch handoff records base `1cb4b0af6361e3d1a1821db87650c20a79ab7270`; its base tree object was unavailable in the inspected local repos. The patch/hash and host receipts authenticate this variant. Original app LINK equivalence is unverified. ## Host checks for the next implementation slice

Use an isolated source copy and the pinned original inputs. The following are existing executable starting points, with the extra acceptance assertions to add when a control is exposed.

1. **Oscillator/SUB/FM/NOISE and FILTER type/pitch tracking.** Run `sh tests/host/synthone_patch_test.sh`. Run the existing production UI harness with `SMC_UI_TEST_FILE=tests/host/ui_synthone_patch_test.c`, `X0X_SYNTHONE_PATCH=1`, and `X0X_HOST_DEFS=-DX0X_SYNTHONE_PATCH=1` via `sh tests/host/smc_ui_test.sh` for the documented INIT profile. Extend the slot assertions for each newly authorized ID and the real next-detent, min/max, units, ownership, stale edit, list and save/reload paths. Repeat with actual compact backend flags and the verified pack in a profile-aware fixture. Compare oscillator/filter output against original-law observations on both parts before claiming original behavior. Use exact upstream binding evidence before assigning waveform or selector captions.
2. **LFO, routing and wet FX.** Generate test assets with `sh host/build_host.sh --generate-only`, then run `sh tests/host/s1c_fx_controls_test.sh`. Extend the production UI fixture to drive actual physical inputs for each destination and idempotently round-trip the applied target and saved cell. Compare pre/post PCM, echo spacing, and wet/dry tails. Drive app-authenticated mod-wheel cases 0/1/2 separately, including synced vs free rates and preset/part ownership. Test gates with effects on and off.
3. **Original ARP and app tuning.** Run `sh tests/host/synth_arp_hooks_test.sh` for the shared engine/storage behavior and `sh tests/host/ui_arp_seq_test.sh` for UI routing (uses fake hooks). Compare real hook event order, pacing and gate to the original reference driver `python3 tests/host/run_synthone_sequence_static.py --source-build ORIGINAL_BUILD --output OUT` with matched mode, division/BPM and preset transitions. For tuning start with `python3 tests/host/test_synthone_tuning_reference.py` and require a real A4/master-set gesture, note-frequency readings on cross-octave notes, and project round-trip. Keep app tuning and held-note behaviors separate from stored patch metadata.
