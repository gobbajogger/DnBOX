# Run the joint host check

From this directory, run `python integration_test.py conservative-journal`
and `(cd conservative-journal && python -m unittest -v)`.

The combined test admits the reclaimed PANEL sectors only at the eighth
and final named operation once both journals validate against the same
verified backup. It checks SMK-37 Elite/Pro fixture identities and either
old active side. It places only synthetic reproducible immutable bytes
in memory, then verifies restore-first rollback recovers the entire exact
legacy image. It does not use reclaimed sectors as the sole copy of
user-created data. The six independent migration cases cover 35,824
migration and 8,702 active-edit simulated prefix cuts, 44,526 total.

This adds no installed capacity. Native write window, rollback workflow,
playback, and physical package validation remain essential. Bank data still
needs 176 KiB. No model result authorizes firmware publication or flashing.
