# Synth One vs SuperJ6 original effects: static evidence

**Answer:** One active tail kernel is convincingly shared (AudioKit/Soundpipe Costello RevSC). The original complete effects chains are not the same. Bundled unused AudioKit classes do not prove active routing or kernel identity.

## Scope and evidence

- Synth One original source-derived full-FX render in DnBOX `73749f55`, `tests/fixtures/synthone-factory/SOURCE-MANIFEST.json` pins upstream `6466a3715c96b7ecf1dd255a218cbd571408a314`. Stage source: `fullfx/source_fx.hpp`. Soundpipe source: `fullfx/upstream/AudioKit/Core/Soundpipe/modules/`.
- SuperJ6 original Build9 AU binary validated by checksum-pinned SHA-256 `a5243e50bda6bd44f463c6e63ea3137802142f55f3c1ea25a5a6e046acba81a1`. Read-only Swift metadata plus ARM64 immediate calls on this binary. No app install or fresh PCM captures. `branches.py` prints exact direct branch/call targets, and `revsc_fingerprint.py` checks the public Synth One coefficient table in the AU. Private binary, raw symbols dump and app bytes remain local.
- The private existing `sj6-arm64-bench.zip` README and `bench/fx.py` distinguish which nodes have machine code vs Python substitute. Except for the real J60V2 kernel selected for Chorus version 1, this benchmark's _post-oscillator output rendered from its FX pipeline_ approximates effects and does not establish full original PCM parity.

## Substantive reuse

Reuse a single **parameterized RevSC core implementation** if it can fit budget, with separate owner/engine histories plus each correct wrapper. Do not share its live histories or merge knob laws, damping, compressor, and taps. At 44.1 kHz, straight original Float32 DelayLine allocation formula alone is 24,690 samples = 98,760 B per active reverb (197,520 B for two histories, excluding descriptors). Original 48 kHz path is 107,440 B per reverb before metadata. Merely sharing code saves flash, not live history capacity; a common reduced representation requires new impulse/tail/null and timing comparison. For delay, only reuse lower-level access/interpolation helpers, not one unified receiver topology. No requirement implies a shared full-S1/SJ6 effects pipeline.
