# Synth One delay: isolated, not a merge candidate

The same exact six corrected reference WAVs, calibration and recovered source were used as s1-controlled-ab. No reverb code, controls, references, alignments, or gain fitting were changed. FX-disabled captures remained exactly equal to recovered source on six of six.

`f8.patch` replaces only the elastic delay's external ring sample format with signed E5M2, allowing twice the history sample count within the same 2,152 B and same structure sizes. It uses the existing byte pointer, handles zero, saturation, and the existing in-place warm-history regrid. All other native/legacy variants remain on the original F16. Scratch witness: `verified.report.json`, `render.log`, `pad-band.log`. No native timing/link, hardware, Git, or publish.

Pad ddec 45 -> 23; last-second error -6.299 -> -3.259 dB, whole spectral distance 13.427/15.431 -> 11.746/14.516 dB, but whole channel levels -3.403/-4.190 -> +2.001/-2.446 dB and raw residual +1.357 -> +2.124 dB. The last-second 500-1000 Hz deficit improves but higher bands remain heavily down. Other delay-active presets have mixed effects (especially 128/278 right), so do not merge. Organ and Bass untouched; 435 wet is also exactly unchanged. `trial.py` tests cubic interpolation, last-sample input (aliases), disabling legacy wet trim, and exact-original feedback scaling individually and combined; no variant achieved six-pair parity.

Causal high-bandwidth control (not deployable): `unlimited-diagnostic.json` swaps only the external half-float ring to 240,000 B in a host harness after selecting program, setting Pad decimation 1. Pad last second -0.119 dB, whole L/R +0.864/-0.103 dB, spectrum 1.181/1.750 dB, raw waveform residual +2.064 dB. Confirms compact delay bandwidth is the dominant Pad late-tail loss, but high bandwidth alone does not reach waveform null. Organ -4.697 dB unchanged.
