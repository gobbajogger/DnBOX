# Synth One host-only delay-off RevSC witness

Nothing in this source package is a firmware or installer change. The prototype is protected by a non-host compile error, deliberately freezes the delay-off arena owner at first render, and cannot safely re-enable Delay. Do not graft it into a runtime build.

Apply host-only-eight-line-revsc.patch with patch --fuzz=0 -p1 against the exact recovered ab-latest-headless translation units, or copy the donor's firmware/src/dsp/s1c directory, apply those two files in the isolated test tree and link the donor s1c_part.c/s1pack.c against the modified s1c/s1u/s1c_front files. Build under the same host flags as s1-controlled-ab/build-run.sh, preserving the recovered S1 flags and -ffp-contract=off/-fno-fast-math. The local callable command is bash s1-reverb-revsc/build.sh render-final-host-only once the isolated donor mirror is present (copy header dependencies one level above s1c as in the original build). Use s1-controlled-ab/render.c and the exact private stock FDATA only as a bench fixture; no packed data belongs in the source bundle.

Run 001,062,113,128,278,435 in wet mode against the corrected 44.1 kHz/264600-frame unity-calibrated references, with the 128-sample preroll and scheduled note edges already in render.c. Capture headless margin using s1-controlled-ab/measure.py against the same fixed reference calibration. Compare every non-Organ candidate f32le to preceding recovered wet output byte-for-byte. Reports in final-results.json do not contain PCM or original values.

Organ: whole L/R -0.840/+0.302 dB, body -0.338, full release -0.047, last second -0.050, spectra 2.631/2.530; passes the recovered level tolerances and the same independent valid spectral diagnostic. All other five are bit-identical and total result 2/6. The original eight line timing family and junction/scatter are reduced to 1/6 rate with a signed 8-bit float code in the dormant Delay arena. Wet-only anti-image is a four-pole streaming filter; low-level feedback remap compensates compact transport, preserves zero and unity endpoints. The branch only activates when actual Delay is off and Reverb on, not by preset identity. Total already-allocated arena remains 4,252 bytes; no additional owner or heap. Final native fit/timing, image parity, transition safety, and wider instrument corpus are not qualified.

Future integration should not appropriate dormant delay storage before deriving safe ownership. A candidate path is estimating original room with approximate 4-bit adaptive history at a lower rate in the existing reverb-only allocation, retaining live dormant delay history; this is untested.
