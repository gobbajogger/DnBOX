# Native combined LINK UI: guarded activation and lossless page sizing
Source: untouched remote-both-link/tree donor, with baseline paired build receipts in remote-both-link. Toolchain and flags pinned by build-fit.sh. Diagnostic linker instrumentation only adds -Map against unmodified bounds; it is not a patch to ship. Existing generated files/packaged hashes cannot prove a failed link and were not used as evidence. All input and worktree changes are isolated.
- Existing build flags leave X0X_SUPERJ6_BUILTIN_INIT undefined, so the originally reported +4,380/+4,368 B does not include the real SuperJ6 panel and LINK. The exact hidden-SJ6 Elite baseline reproduced +4,380 B. sj6-native-init-provider.patch provides explicit guarded opt-in, retaining default behavior and only accepting Elite/Pro Factory builds. No production guard disabled; no diagnostic release.
- With actual SuperJ6 controls admitted, Elite/Pro overflow were 6,580/6,572 B; sj6-compact-page-refs.patch reduces each by 704 B, to 5,876/5,868 B. Both active maps include engine_superj6_knob_turn and linked descriptors. Native display code describe_pages decreased by 758 B (0xf28 to 0xc32); the compact table plus padding consume part of that saving. The identical logical six rows, all physical knob positions, shared owner, type, count, order, labels, and marker values are unchanged. No DSP, timing, project save format, or Remote path touched.
- The two source patches both dry-run on base with zero fuzz; they do not include the map instrumentation. Full hardware builds still fail hard XIP. There are no verified flashable images from this experiment; no writes, no release, no claim of later full controls parity.
- Baseline and compact host both pass exact same fixtures: 40 checks Synth One, 322 checks SuperJ6. All four actual OFF/ON A/B screen captures match all 230,400 decoded RGB pixels across variants (see captures.log). No native runtime validation because XIP fails at link.
