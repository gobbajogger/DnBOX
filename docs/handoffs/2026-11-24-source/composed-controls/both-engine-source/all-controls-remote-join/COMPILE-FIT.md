# Both-engine source batch: compile and ordinary fit record

One source composition contains both original-control firmware registries,
typed Remote transport, physical keyboard UI, guarded project admission,
one LINK per engine, and the matching website patch. This does not claim
complete original inventory or behavioral parity. The old 13-control trial
was not used as the full candidate. Factory banks remain out of the INIT-only
test profile. Controls and arp were not cut to obtain the result.

- Actual JieLi translations emitted all application objects for Elite and Pro
  after source reconciliation. The compile-only phase stopped before linking.
- Replayed the exact original_sound C and H, SuperJ6 factory parser header and
  matching 909 renderer C and headers from one archived manifest. The control
  UI is a source reconstruction, not the unavailable historical exact file.
- Ordinary APP link with samples and tables in stock placement rejected
  Elite +133,716 B XIP and Pro +133,704 B, with no unresolved symbols.
  Elite's mapped pool is 0x52a18 against 0x54000, or 2,584 B short of the
  required 8 KiB reserve. No runnable package is claimed.
- Largest immutable stock Elite map entries: 909 ride 23,500 B, crash
  21,650 B, hats 10,125 B and Chicago E/A tables 17,558/8,130 B.
  Large source areas: pref_set_impl 14,848 B, do_undo 11,756 B and
  describe_pages 10,420 B. These are mapped sizes, not guaranteed savings.
- The guarded companion experiment is isolated, never installed or shipped.
  No runtime, sound, or parity test has started on the composed source.

Inputs: both Remote panel adapters, protocol and shared wrapper, reanchored
UI and compile repair, project tuple and transport replays, schema routes,
the pinned 909 closure and source-only SuperJ6 Fatten DSP replacement.
The compile runner expects matching generated headers and the private SDK.
No private assets, binary firmware, or render captures are included.
