# Synth One controls: original app callbacks to guarded firmware source

Canonical app: AudioKit/AudioKitSynthOne at `6466a3715c96b7ecf1dd255a218cbd571408a314`, verified from repository file contents, not inferred from AU enumeration. Canonical DSP: matching pinned source closure from firmware `assets/test-inputs/synthone/MANIFEST.json`. Inspected combined candidate `auth-vintage-fit` plus isolated `s1-original-whitekeys-v2.patch`. This is source coverage only; it is not claims of native build, runtime pass, original audio fidelity, or final release.

Explicitly outside direct engine parity: iOS waveform plot fill/line, recorder/recorder export, navigation and MIDI-learn screens, iOS keyboard appearance/width/drawing, and tuning bank import/edit/reorder/random-selection workflows (random selects from current tuning bank in `Tunings/Model/Tunings.swift:367+`); their controls do not add independent ongoing engine parameters. A playable imported table is separately implemented. The four HAQ Freeze controls (`DevViewController.swift:158/164/170/187`) change factory program application only: Freeze Arp Rate, Delay, Reverb, and Arp+Seq. In the owner-directed INIT-only build there are no factory programs to apply; no dummy Freeze toggles were added. Raw AU IDs 18, 33 and 145 are source-marked unused/deprecated, and 31 is internal detune multiplier; none has an independent original panel callback.

Original external Mono dispatcher highest remaining raw MIDI note is separately authored in s1-midi-mono-resume.patch, including exact release velocity entering the direct note-on receiver (a velocity-zero wire packet still remains Note Off). This is not the underlying local DSP's recency priority. The app's default MIDI Learn CC71/CC74 assignments were not added as hardwired engine controls. The physical device's separate live owners and explicitly sequenced track roles remain independent by design.
