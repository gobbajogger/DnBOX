# SuperJ6 Build 9 velocity settings, source-only handoff

Original AU (authorized local binary, no embedded original bytes) exposes two independent performance controls:
- Settings MIDI storyboard connects velocityTaperSegment to midiVelocityDidChange:. AU callback 0x1002becb0 -> 0x1002bec44 reads selected index, mapping 0 Soft, 1 Medium, 2 Hard. 0x1000448a8 consumes the exact Double constants {0.4, 1, 4} at 0x100607408. Conductor normally initializes 1.0 at 0x10026158c-1598 and app settings persist it.
- AboutController connects FIXED VELOCITY ID205. Constructor 0x1002612c0-1330 creates ID205 initial zero. Normalized input is interpreted as >0 by 0x100272db4, and writes the isFixedVelocity Conductor ivar through the reference at 0x10080a418. Original listener 0x10001a29c-2bc chooses literal 87 when that flag is set, otherwise input velocity; raw zero first follows its separate Note Off route at 0x10001a480. The selected positive value is used for ARP capture at 0x10001a618, and otherwise passed to the full MIDI path.
- Full direct MIDI handler 0x1002f06dc-0768 bypasses the taper when the ARP owner is engaged, and otherwise computes Double(pow(Double(Float32(raw) / 127), 1/exponent) * 127) then truncates. Map domain is 0..127. Direct DnBOX UART/USB/BLE route uses exactly this discrete mapping; even Medium includes original Float32 truncation. An original transformed value of zero is an attack, not a raw zero Note On or release.
- Settings > Keyboard has a separate position-sensitive Fixed/Normal/Inverted touchscreen presentation choice, not a second spelling of MIDI Velocity Curve. The actual About Fixed Velocity knob is wired for native live input; don't invent a screen-Y to scanned velocity mapping or count an iOS touch mode as an engine scalar. Velocity Lock applies to preset loads in the original and is out of the Init-only scope.
 
The isolated patch adds actual source receivers, owner-scoped project byte T_MST[5+owner][29], WHEELS K4 Fixed and VOICE K4 MIDI curve. Source intentionally retains original untransformed local key velocity when Fixed is off, raw note recording, and already-programmed DnBOX sequencer velocity; no Chicago/Miami/Synth One behavior changes. Legacy all-zero sidecar encodes Medium/off. Undo reads and bounds the row before applying under the existing typed sound edit hold; direct audio edge input reads the authored byte from the live sound, so no separate DSP reload is required. Compile-time flag X0X_SJ6_VELOCITY_SETTINGS=1 must be added to both paired flag lists. Source only, no compile, fit, or tests run.
