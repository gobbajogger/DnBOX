# Original Synth One MOD → LFO rate receiver
Base controls-init-only/source-mod-wheels (b71f366f). Reproduce from workspace with `sh perf-final-proof/s1-mod-rate-probe/run.sh`. Patch only adds opt-in `X0X_S1_MOD_RATE_PROBE` receiver and fixture selector, never enabled by default; does not add product UI or project writer.

Original 6466a371: Keyboard/WheelSettingsViewController.swift shows Cut-off, LFO1, LFO2 and dispatches selected segment index; MIDI/Manager+MIDIListener.swift forwards CC1 to the same pad; Manager/Manager+callbacks.swift switches activePreset.modWheelRouting, routes 1/2 use setDependentParameter for LFO1/2 RATE, not depth. Original source_controls.cpp and S1Rate.hpp: free normalized CC uses x^(1/0.4) over factory ID 15/47 bounds; sync casts x*18 to integer (truncate), converts that division to physical frequency, then clamps and snaps to nearest original frequency in bounds. Reuses compact front end for second pass. At 200 BPM top triplet exceeds upper bound in the binary32 path and falls back to preceding straight division. Routes 0 and invalid requests retain baseline (invalid is rejected, no side effects).

Fresh run 4,682 checks: each route on each owner, real SMK ADC handler and channel MIDI convergence; 128 MIDI values in free, 120, 200 modes; held physical wheel keeps first part after a UI part switch, no peer/other LFO/cutoff mutations. No project Sound change or writes from wheel. Explicit later save/reload plus cold engine reconstructs baseline rates and default routing. Cold reload of a selected alternate route is intentionally not implemented. Fixture seeds mode/BPM at compact front end; no claim about original clock takeover policy, timing, or native XIP.

Storage: old and current files key owner-specific authored state to valid Synth One records. Standalone fields [21] bit7/3–5, MSBs of [0..2] and [3..5], [30], [31] are already assigned/reserved, not available for independent new routing. [30] mode Cartesian factor would need 225x3=675 values; 8-bit field cannot carry. Two independent coarse codes require 38x38 values; x3 exceeds the 12-bit field. Bend-range schema3 proposed earlier also needs central Sound-tag and note-lock-accounted versioning; not standalone. No opaque row/tag allocation. Future coordinated schema must prove per-preset selector is separate from transient wheel position, preserve note-lock/held owner and original cutoff default, and old reader rejects without persistence.
