# Engine-owned bass automation

Automation never rejects a preset or engine request. A same-engine selection retains active lanes. A cross-engine selection parks the departing engine's lane metadata without editing step values, and activates any retained lanes belonging to the replacement. A queued pattern preset that adopts at the first note replays the incoming engine's locks before that note. Pattern copying and lock indicators do not mistake parked lanes for live controls. Reset and undo treat the sound and its associated lanes as one edit.

Project stream 16 stores the exact sound and arrangement together under the existing whole-stream CRC. New-format saves leave the separate legacy sound object untouched. Existing revision 13–15 projects still load. A recovered previous-copy project remains exportable and is fenced from further saves; this prevents an interrupted retry from overwriting the last valid generation. A near-capacity older project may not fit the larger compressed tuple; preflight refuses before writing anything in that case.

Focused host tests: `bass_automation_switch_test.sh`, `run_project_stage.sh`, `engine_automation_project_browser_test.mjs`. The storage fixture exercises 216 actual simulated erase/program cuts on the host (both first upgrade and subsequent saves), no-fit preflight, unknown format refusal, and exact fence/export recovery. A device still validates a browser import before it can replace samples. Both Elite and Pro link with the existing flash floor and pool reserve. No production release, flashing, or full combined performance gate is claimed.
