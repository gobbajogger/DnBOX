# SuperJ6 J60 wet-only source comparison
Run from workspace root: `bash sj6-raw-j60-wet/run.sh > result.json 2> build.receipt`. Read-only donors and private original references match those documented in adjacent sj6-raw-j60-middle / sj6-raw-j60-common receipts. The driver checks donor/output and terminal-reference hashes before scoring, then enters signed real compact pre-J60 PCM into an authentic older ARM64 J60 owner. Score compares its exact wet-only 96 kHz return to the separately compiled current compact 96 kHz core (identical ordered samples, two channels). No outer down-conversion, direct-path impulse model, terminal normalization, phase fitting or PCM export.
 
At .518c–.545c, original filters each channel into two double biquads then DC/HP and writes a 1024-word double ring. Phase uses two rounded F32 adds (detune, then angular increment) with +1 / -2 left/right phase relationship. Center is smoothed with F32 FMA and snaps from stagnation, then multiplied by 16384. Delay address wraps positively, linearly reads current and next address; original interpolates in double. Its post low-pass integrates twice with the same reached x0+0x25380 coefficient. Zeroing x9 at .5440 removes only direct 1.3×input, not wet amount, BBD state or wrapper. The donor's stock compact core is unchanged outside temporary builds. “delay” means jointly original center representation plus numeric addressing, not a different physical delay/ring choice.
 
The state discriminator logs eight exact phase/center, mode/rate/depth/mix and relevant state/coefficient observations including cold, warm and active audio. Source final output is an independent signed measurement; no decoded proprietary audio or binary included. This is isolated old-original wet behavior, not a newer installed app capture of this intermediate stage, distributor release, device timing, full dropouts or hardware qualification.
 
**Decision.** The original post integrator step is 0.2516540875455158, not compact's 0.533294672 (which belongs to the input biquad, not the post integrator). It is a unitless per-sample update coefficient at 96 kHz. Changing only this coefficient reduces signed wet residual in every authentic same-input Raw window (attack, held, first release, chord and last tail). Exact phase-only and center-only don't pass the five-window guard; combined has worse chord performance than post-only. No output gain or time alignment.
 
Connected check invokes the actual compact 44.1 kHz bridge with identical segmentation. Stock bridge full output must equal its real pinned renderer tap bitwise or abort. Post-only improves wet residual in all windows relative to the old J60 driven by that same input. Absolute compact-vs-newer installed AU mixed terminal error remains essentially unchanged for Raw: dry/source and bridge remain distinct blockers. No production adoption. The optional host-only patch leaves native/default behavior unchanged and has two changed coefficient uses but no new state or changed operation count; no native code/cycles/fit claim.
