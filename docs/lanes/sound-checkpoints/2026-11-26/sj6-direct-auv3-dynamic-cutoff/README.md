# SuperJ6 AUv3: cutoff events during held notes

These direct native references were generated by the reusable Mac bench.
Both arms start at the same cutoff. At frame 24,576 the treatment opens
only physical cutoff #7, and at frame 61,440 it restores the authored
value. The control arm performs identical timestamped writes that leave
the parameter unchanged. Each arm was repeated.

The held tone changes after the first step, then converges after the next
note onset although the public parameter remains open. Restoring cutoff
during that next note creates a new large change. This localizes the
remaining issue to live note/voice processing, not a generic time
ramp; it does not establish which component overwrites or supersedes it.

Run `python3 score_dynamic.py` here with NumPy to verify the exact inputs,
all readbacks, PCM SHA values and measured windows. Full receipts and the
four arrays are also saved in ChatGPT Library.
