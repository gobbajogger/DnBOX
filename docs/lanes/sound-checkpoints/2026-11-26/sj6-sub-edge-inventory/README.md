# Does a simple Sub edge correction address the signed source error?
Test the real pinned source map on independent strike, early body and
both wrap boundaries. The analytic fundamental describes phase and
amplitude in the best-case input domain. A stationary phase template
is learned from a separate late-loop interval. Select edge neighborhoods
by the template's own slope, not the measured residual. Score the
unavoidable residual outside those neighborhoods even if edges were
corrected perfectly. No per-preset or global gain adjustment, source
audio export or native implementation.

The median share of residual outside the edge mask is 72.74% at strike,
67.92% before wrap, 10.79% in early body and 5.95% after wrap. Changing
a single edge shape or phase may help body, but cannot explain whole
strike and wrap mismatch. Actual candidate must preserve or reproduce
between-edge temporal shape as well. This test has no data residency
or full-engine claim.
