# Table-free four-segment Classic history diagnostic
No production change. Repeat host actual-input A/B with `bash rebuild.sh <exact donor root>`; then only in a disposable native diagnostic `bash native.sh elite 1` / `bash replay.sh elite 1`. Baseline stock native receipt is the identical boot probe saved by adjacent block-scaling experiment, same source/flags; availability of full image is not necessary for inspecting this source-only receipt. Emulator runs same two independent Classic BOTH owners and exact 24 MHz bracket as block-scaling measurement. This is not full firmware performance.

One fixed signed 16-bit word per slot, unchanged 512 B/owner, no exponent state/table/prefix rewrites. Each segment has 8192 magnitude cells; decoder uses just bit operations and at most two compares. First segment old Q15 codes through .25, top representative ~73.24 with rising quantization steps. Support range is conditional (e.g. centered Normal pre-FX raw ≤48 under amp/velocity ≤1), not proven for arbitrary OTA/upstream routing. Exact stock read time and interpolation, unchanged dry branch.

Eight actual six-voice source tapes give −70.71 to −71.65 dBr wet residual vs float; low case and late low-level decay exactly stock, active release up to 2.68 dB more residual (several exact). This does not match authentic original production output and does concede precision versus the more expensive block-scaling and eight-segment routes.

Actual PI32v2 paired max 869.83/866.54/866.50/872.96 μs versus stock 540.46/534.33/534.38/536.21. No history rewrite burst, but +329 to +337 μs steady penalty is still too costly for 100 μs planned headroom. Low fade digest is identical at 7bb86cbb. Same native type sizes 4948/12212 and pool 564. Diagnostic XIP +160 B, no physical flash or release mutation. Reject candidate.
