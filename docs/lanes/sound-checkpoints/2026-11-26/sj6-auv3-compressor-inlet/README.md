# Direct SuperJ6 compressor calibration: the gain gap is upstream

Direct offline Apple / installed genuine SuperJ6 AUv3 on the same Mac, 44.1 kHz stereo and the same signed sample boundaries. Neither changes settings in a saved preset, plays sound, or writes a physical device. No original binary, preset bank, or protected app source is included. The diagnostic is not a firmware change.

The Apple component is aufx/dcmp/appl. Exact sorted parameter readbacks are in bare.json. Direct rendered unity bypass agrees with its deterministic input within 1.26e-8. The original AU used pinned factory Jupiter Sine, the OSC2 fader only, true public compressor control raw 0 / Float32(.02), and explicit Vintage0. Seven faders each have one matched off/on pair; two additional exact on/off pairs reverse collection order. The held-out faders were not used to determine the model; both sides' RMS and tone amplitude, two sustained windows, and an onset check are reported.

Run `python3 score_compressor.py native` (NumPy). Across training and held-out faders the common surviving equivalent pure-sine peak at the compressor inlet was 0.73978–0.80151. Best maximum residual 0.102 dB, measured repeat spread 0.102 dB at worst; bare repeats matched. Peak is an equivalent calibrated amplitude, not an internal PCM tap or an exact waveform shape. The compressor-off measured .083451 RMS yields 0.1472–0.1595 implied downstream scalar using the same sine approximation, containing directly inspected .404×.44618×.85 = .1532. The actual off tone has a harmonic near -30 dB relative to the fundamental. Neither the conditioned upstream isolated oscillator witness (peak .2768) nor adding an extra .707 downstream explains this result. The experiment rejects correcting the discrepancy with a blanket late gain. It does not name the missing upstream stage, infer a general preset gain, or qualify firmware.

To reproduce capture, use add_compressor.py and bare.swift on a scratch copy of the approved direct AU bench main.swift/submit.py with the earlier jupiter-poly profile present. Compile into the offline host app and run `jupiter-compressor`. The data and exact capture receipts are also saved to ChatGPT Library.
