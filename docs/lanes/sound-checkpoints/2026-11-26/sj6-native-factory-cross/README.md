# SuperJ6 native original factory-preset comparison set

Original installed macOS AUv3 build 9, not compact output, captured with the
same S4 44.1 kHz stereo MIDI cue and 16,384 frames of warmup. Trim exactly
the recorded warmup for comparisons; no time shift or normalization.
Three independently authenticated factory records include authored effect
settings, a dry-effect control ablation, and a fresh authored repeat.
Brainwave's installed readback differs on two named controls; capture
metadata records them so a compact comparison must not treat that pairing
as fully matched without verification. Solidify and Raw J106 had no
overlapping parameter mismatches. User Bank Init had no authored parameter
records and was deliberately not accepted. These are real patches, not
OSC/fader variations of a single patch.

Dry ablates only public #11/#16/#17/#22/#23/#24/#40/#41/#107, not arp,
voice shape, tuning, or preset-specific rules. It does not assert every
unknown original transport/branch is genuinely bypassed. No original
assets or plugin executable are part of the checkpoint. Renders, per-arm
capture manifests, and the public host fixture function are included.

Original's authored effects changed held-note/chord RMS only −.05/+.04 dB
for Brainwave, about +3.49/+3.82 dB for Solidify, and +4.42/+2.03 dB for
Raw J106; the Raw J106 early release was +6.10 dB. Solidify's authored
repeat early release differed by −1.32 dB and has a meaningful native
repeat floor. These numbers describe the original only. No compact
mismatch or cause is inferred solely from the original unless a
source/clock-verified compact counterpart is also scored.
