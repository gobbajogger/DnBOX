Host-only DNL2 selection and staging. Inputs are authenticated immutable bytes owned by the caller; CRC is corruption checking, not authenticity. Call stage_program with DNL2 engine tag, bank ID, preset ID and a trusted expected ordered schema from the authorized catalog, never one inferred from incoming untrusted data. On failure the output is empty. Its only positive state is STAGED_NOT_ADOPTED; no owner runtime or flash is linked. The corpus harness pins the original input archives before rebuilding existing DNL2 banks in memory. It verifies full signed binary32 words, ordered IDs and names. No bank images or binary artifacts included.
