# Synthetic lab-only arithmetic speed proof
One measured 512-frame segment each in strict PI32 emulator with same synthetic RNG input, parameters, transposed+once-hoisted topology and fresh history. First arm calls exact single-precision software FMA; second arm explicitly does rounded binary32 multiply then add exclusively inside this laboratory leaf with ffp-contract=off. FMA helpers remain present for exact comparator and no global/project/deployed arithmetic was modified. Candidate undefined symbols only fm_tanhf and memset. No DMA, IRQ, playback, firmware link or device.

24MHz crystal TIMER4: exact software FMA 2,827,071 ticks / checksum 0d5fd915 (identical exact checksum to independent earlier bare comparison), separate multiply/add 49,617 ticks / 08e73264, 56.97787x faster (98.24493% fewer ticks, 230.0676 vs 4.03784 µs per tested input frame including PRNG/hash overhead). This is one nonrepresentative fixed call, not a target audio-frame/worst scene claim. Distinct checksum is expected: this is not bit exact and the fixture does not attest original audio tolerance, other authored controls, initialization/admission or A/B wave parity. No production FMA weakening. Exact source fingerprints in build.log; no generated assets or package.
