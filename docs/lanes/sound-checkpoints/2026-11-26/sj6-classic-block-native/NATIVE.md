# PI32v2 native diagnostic (not a release build)
Compile two Lean Elite ELF arms via `bash native.sh elite 0` and `bash native.sh elite 1` then replay each with `bash replay.sh elite {0,1}`. Uses same exact retained toolchain/build donor recipe, native pins noted. Emulator only, no release writes. Hosts two independent actual stock compact Classic BOTH processors on four existing owner scratch arrays before init; measures both owners sequentially in same 24 MHz timer bracket and reports max of eight warm 256-frame spans. Not an actual audio ISR or integrated scheduler. All FX input synthesized in test to isolate leaf cost: high-level deterministic steady noise, quiet fade, one late lift, and seven late exponent climbs per group. Input conditioning happens outside timing. Recurrent test reaches conceptual 196 previous-sample conversions/group each owner. Timing excludes other engines, arp, Remote, ISR bookkeeping. Enabled diagnostic build compander is not dormant in that binary; kept entirely isolated from production.
