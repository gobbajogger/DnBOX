# Native BF16 Widen same-workload extension

Run this only as sole emulator owner. It builds no installable package and does not touch hardware or Git. Offset zero only. The two retained H16 and the two older allpass captures were independently sealed and replayed previously, not reused as BF16 input. All six captures use the 922 exact events, 360 MHz, strict/no-skip, 8 s, exact byte-equivalent six project sectors and owner marker, two loaded parts (Synth One A with arp/room/width, Chicago B), and board-correct overlays. Comparing point owner polls is not a proof of continuous controls/voice state.

The BF16 diff is a sample encoding replacement of the H16 4,410 B right delay ring; Widen clock, mix and everything else in the runtime source remain intact. The codec has a wider exponent range and fewer fraction bits than H16. It does not independently establish audible parity.

Reproduction in project workspace after matched old/H16 receipts and cold fixture:
    bash widen-native-verification/run-bf16.sh > widen-native-verification/bf16.log
    python widen-native-verification/verify-bf16.py > widen-native-verification/matched-bf16.json

The second command verifies exact ELF pins, guard-sealed seed, matching SRAM/owner view, exact event and six sector hashes, unchanged NOR, active Widen at 1 and embedded payload position. No widening fit credit other than unchanged native link counters on these diagnostic builds.

## Verified results

| Model | Allpass | H16 | BF16 |
|---|---:|---:|---:|
| Elite | 15,840 µs / 105 XRUN | 15,558 µs / 39 XRUN | 15,342 µs / 132 XRUN |
| Pro | 15,801 µs / 108 XRUN | 15,793 µs / 53 XRUN | 15,335 µs / 146 XRUN |

All six saw zero skipped cycles. Each late count equals its XRUN count. Loaded NOR stayed identical and reported zero erases/programs. BF16 targets were exactly 1.0 with embedded histories and tracked ring positions 22 and 1,674; both dumps' histories were empty at the final quiet endpoint. Both BF16 runs lower the observed max relative to H16 but increase actual missed callbacks. No version is a candidate for a strict 10,809 µs, zero-dropout release from this evidence.

## Observer refusal, no attribution

The H16 Elite stock-compatible observer was attempted using the exact unchanged sealed seed and selected original ELF offsets. Only five verified target symbols were used. With the original extra `FM1_NO_SKIP` timing override the observer refused before any replay; with the archived observer's strict/no-extra-overrides settings the runner again refused before replay because the candidate NOR contains protected app-region bytes different from the stock package. The fixture length was exactly 1,048,576. The observer requires an exact matching supported package or loader; it was not bypassed. No trace, timing invariance, or stage attribution is claimed.
