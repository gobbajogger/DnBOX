# Unconstrained Synth One host parity candidate
The actual DnBOX host voice and parameter ingress now feed the four original float histories, tracking low-pass, stereo high-pass, RevSC, independent original compressors, original post-master width delay, in production source order. No previously captured wet signal is injected. This scope is host sound; fit and hardware are deferred. The program import and source maps are separate from preset-specific corrections; none were applied.

Run from the workspace containing the exact restored source dependencies: `bash build.sh NEW_OUTPUT_DIRECTORY`. Each named test arm uses the same actually driven voice. `bank-compare.py` cold-starts both renderers for each selected matching ordinal and uses exact MIDI and finite stereo Float32 output without gain fitting, EQ, realignment, or resampling.

Independently measured against original source: 062 Pad right tail level −6.54 to −0.05 dB, final right waveform residual −26.17 dBr and left −18.10 dBr; 113 Organ late output +0.008/+0.007 dB and residual −42.54/−42.51 dBr. This is a much closer result, not a bank-wide parity claim. Full separate comparison uses the exact 906 recovered authored preset command pack and does not change project-wide tuning.

## Full bank identity and staged host witnesses
The original command dump stored 143 of the 906 rows at different positions than the compact pack. Comparing raw ordinals without reordering was invalid. `align-bank.py` matches the exact 144 command words for every occurrence against the independent C-parsed pack witness and creates the aligned command stream. Always pass its `--identity` result to the bench. After alignment all 906 rendered; 558 were within 1 dB level on both channels, 307 had whole-residual no worse than −20 dBr on both and 25 no worse than −40 dBr. These are descriptive counts, not an acceptance threshold. The first corrected bank test used identical key input but did not yet play the same underlying arp events or saved project-wide scales.

Added host-only switches for the original noise RNG and sample cadence, exact per-voice Soundpipe filter clocks, the 52-table source main oscillator, and separately original Sub and FM. Run every change across the same original bank; do not keep a preset-specific compensation. Some source-derived changes materially reduce errors (e.g. Hats, ZAP, Arcade Lead); other difficult cases remain. Note tape replay isolates sound from the production arp scheduler: it verifies identical emitted/consumed events, does not claim firmware arp parity. Authored tuning is applied on both comparison arms only for the 16 exact custom cases, never as a quiet per-track change in the build.

The second comparison includes the original main wavetable read, original noise recurrence, exact filter ticks, verified raw note tape at the voice entry, and authored tuning in both arms. 906/906 rendered, 900 within 1 dB in both channels, 558 within −20 dBr and 160 within −40 dBr for full stereo waveform residual. It does not prove all presets match. See bank-unified-*.json*. This benchmark does not qualify live product arp, sound against a new Mac AU, on-device fit, or timing.

Further isolated improvements are independently controlled: faithful sample-hold accumulator improved Noise Splash from −2.57 to −100.33 dBr left, and exact stereo source brought it near floating precision; the same note cue's waveform was never fit by gain or offset. Exact LFO, stereo and sub/FM arms are staged in the extended unified bank run. Look at named failures and audio/spectral errors, not the overall level count alone.
