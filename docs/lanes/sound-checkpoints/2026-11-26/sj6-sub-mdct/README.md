# SuperJ6 Sub: independent sparse lapped MDCT bound

Host-only source-private metric experiment. No source, derived PCM, transform coefficient data, encoded tape or asset included. The original-authorized source pack is read in memory only; original hashes and approximate test scores are safe to archive. No Mac, real firmware, release or new per-preset state. This is distinct from decimated full waveform, predictive audio coding, repeating actual excerpts, and stationary/evolving harmonic synthesis.

Reproduce with current owner bench PYTHONPATH: python measure.py . sj6-cross-preset > result.json; python frontier.py > frontier.json; python raw.py . sj6-cross-preset > raw.json. Tested frozen grid uses sine-window 50% overlap, 512/1024/2048 hops and fixed retained coefficient counts. At full precision all 12 time-aligned reconstructions have maximum error below 1e-12. Sparse arm keeps signed coefficients unchanged except one fixed quantizer (no normalized gain, delay, rate change or per-note model); loss remains observable in signed strike/body and both blind interior/actual-loop boundary windows. Complete count includes fixed per-chunk directory entries (offset+length+CRC allowance), actual compressed/uncompressed minimum on each independent 16-hop chunk, and 288 B zone records. Stored fit beyond those allowances, flash sector and existing atomic-update reserves not counted. The reference coefficient quantizer and pack are implementation choices, not an information-theory bound.

The best grid after allocating unrestricted gross 112 KiB gives 112,991 B and worst signed source-window -11.65 dBr; under hypothetical migrated 24 KiB it reaches -5.07 dBr, and no full zone grid option exists under 8/16 KiB. Reaching -20 across all zone windows requires 538,118 B; no -30 or -40 all-zone grid solution. Gross candidate clears only the source-half 36b39d9d weak 'better than silence' rejection, not audio parity. Raw test preserves original current isolated sampler ownership, authored source cutoff/AMP, MIDI and callbacks; only decoded waveform, in memory rounded back to PCM16, changes. Exact installed full graph data not inferred. See raw.json for signed comparison. Conditional 8/16/24 KiB are not production provider extents and precede existing bank and safety reservations. No timing/decode RAM claim from Python. Each host transform spans 2x hop and needs overlap context and ready prefills before note/loop transitions; variable-rate zlib after each cold restart is not a proven real-time target method.
