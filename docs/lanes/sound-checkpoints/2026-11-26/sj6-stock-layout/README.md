# Compile-time legacy Juno storage reclaim (default off)
Reproduce actual warm typed PCM: `bash sj6-stock-layout/host.sh`. Reproduce independent PI32v2 type layout and legacy-source preprocess: `bash sj6-stock-layout/layout.sh`. The transform removes only the stock voice array, stock-only note age/knob/filter state and definitions of legacy synth functions in the available built-in factory-INIT profile. Stock chorus is preserved independent of stock synth. Enabling in a non-factory or non-INIT profile is a compile-time error. No source-owner migration, OTA patch, control mapping, patch wire/storage format, or simultaneous owner alias. Read only source donor materials.
Both host typed warm Raw dry and authored (148684 samples) are bit-identical off/on and to the prior donor. Guard-disabled stock legacy preprocess remains byte-identical, including its original voice members. PI32v2 layout objects under both model configurations show 268 B reduction per variant/union owner (536 B for both), with common typed layer and knob storage unchanged. Actual paired linked memory region accounting and timing not in this package. Existing baseline protected pool surplus is 564 B above base POOL_MIN=8192, of which 512 B additionally reserved: only 52 B currently spendable until proven link. No firmware, binaries, reference audio, or device writes.
