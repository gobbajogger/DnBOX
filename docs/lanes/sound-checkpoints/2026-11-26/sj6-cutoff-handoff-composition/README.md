# Typed SuperJ6 physical cutoff first-note owner (isolated candidate)

No build flags enable this in shipping profiles. No merge, device, app-flash fit, or native timing has been attempted. This is not a whole-engine sound pass.

Apply candidate.patch at fuzz 0 against the named preimages. The assembled source is a source recovery, not a Git-tip assertion. The fixture overlays only the separately pinned donor original_sound.h in a temporary directory because the recovered old header lacks declarations required by the newer runtime. Neither this header nor any Apple executable, arm64 binary, preset banks, or audio is bundled. The owner fixture substitutes fail-closed abort links for unused Miami, Chicago, and S1 calls; the actual SuperJ6 provider, note owner and raw parameter setter execute unchanged apart from this patch.

- Positive key ingress checks pre-increment externally held-key ownership across sources with a bounded counter maintained from actual map slot transitions (no ingress scan). A matching quantized delay >= 0.01s and destination physical cutoff (#7; not #129 harmonics) submits the authored LFO1 base. Later chord presses/repeated keys do not submit it; a fully empty ingress owner can do so again.
- Public #7 is retained in the existing panel macro and existing raw parameter slot. During a latch its setter clamps the previous live displacement plus the new public value. No direct physical cutoff write replaces the in-flight target.
- Both renderer-layer cutoff parameters receive a temporary live offset via the existing compactor cutoff span and are restored after render. The new smoother reuses the existing audio-frame 80-Hz grid, not an assertion about Mac run-loop granularity.
- The existing project carrier has selector and 7-bit LFO1 base (`original_presets.inc::sj6_aux_apply`, `one[0],one[2]`), and the existing panel delay path is likewise 7-bit. The candidate consumes those values without changing the project format. Existing generic typed runtime parameter ingress can now receive exact original #180 as JUNO6_APP_PARAM_BASE+180, using existing raw value storage; verified .3345831037 exact with every downstream renderer arm. The actual recovered preset loader does not call that endpoint (nearest 7-bit .3385827), so qualification must exercise the carrier values or wire a verified exact loader/sidecar dispatch. Existing explicit panel edits supersede imported live value. No hidden saved controls or extra UI fields.
- When active LFO1's ordinary depth starts writing cutoff it can replace this isolated note target and existing modulation precedence is retained in this prototype. Concurrent physical CC1 cutoff, other competing modulation, arpeggio player bypass timing and active cross-route changes need matched controls/receiver verification; this opt-in cannot be promoted based on the dry LFO-off cue alone.

`sh verify.sh [source-root] [path-to-tested-original_sound.h]` rebuilds both actual hosts and compares opt-in/off dormant stereo PCM bit for bit. Uses ordinary C99 host build, no production toolchain. `preimages-and-source.sha256` identifies exactly the source/fixture files that were tested.
