# Shared four-stage signed Synth One native phaser

Follow-on to the strict no-double adapter, not the stock compact phaser. Make no deployment. Factor the original duplicated stereo resonator into one four-stage implementation, with separate independent valid Float32 states. Keep original operation ordering (including the zero-times-signed-input contribution to wet output) and no FMA contraction. App source fixes Level to exact unity (0dB), Vibrato on, invert off, notch base 100/800 Hz and ratio 1.5. Runtime wet mix, rate, width and feedback remain. 224-byte struct layout unchanged; reference and candidate agree on all 224 bytes after every sample.

Three host spellings checked: noinline shared, ordinary inline request, and forced inline. Each matched 12,200,000 interleaved stereo owner calls with 9,149,472 active, including sustained audible rate detent43 on owner0, independent bypass/release/live rate and width and feedback on owner1 (48k), and signed zero and nonzero subnormal inputs. Samples and all signed recurrence, feedback and control state matched bitwise. Detent43 reaches the cold range path at source sample 5,273,260 in both arms; no periodic phase normalization, argument clipping, range cut or soft-double. These are real phaser stages driven with deterministic synthetic PCM and controls, not qualification of the linked arp scheduler.

Native strict no-double unchanged caps, no stock writes. Earlier direct Elite candidate overflowed by 2,112 B. Shared out-of-line now overflows 1,376 B Elite / 1,364 B Pro before marker (1,380/1,368 with 4-byte marker). Corresponding attempted APP lengths are 554,052/554,040 B. Elite exact savings -736 B: .text.s1_part_render 6830 ->5880 B plus one 214 B shared helper; other reducer sections/state unaffected. Pool unchanged 564 B above floor, BSS boundaries unchanged. Ordinary inline keyword does not change LTO output. Forced inline is bit-identical in host but worsens both target XIP by 224 B: overflow 1,600 B Elite / 1,588 B Pro pre-marker. Reject forced inline. This is actual link limit, not measured full-app timing or pass. Retain source-only and coordinate independent APP recovery; at least 1380/1368 B is still needed.
