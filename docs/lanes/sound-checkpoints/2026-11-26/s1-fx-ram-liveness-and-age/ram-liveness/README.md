# Two-owner Synth One history liveness witness
Read-only on the sealed table-share diagnostic PI32v2 pair; no firmware modifications or timing run. Both model hashes and identical live symbols in pins-and-symbols.txt. This is a worst-case allocation proof from source, not evidence of synthetic audio or a shipping gate.

- NBASS=2 (seq/pattern.h). The two original_bass runtimes and two original_fx owners are separate. original_runtime_init steals only the *same part's* 4,252-byte idle Chicago FX arena; that memory is already in use by Synth One. original_runtime_retire returns it to Chicago only after retiring that part; the other owner keeps rendering.
- Each instance's S1C_RVA pads its four rows to 368,432,496,560 words of payload. BFP adds 116+128 B, so the reverb arena is 2,100 B and the adjacent delay pool 2,152 B. The 2,205-word 16-bit widen ring is another 4,410 B in that instance's backend, already allocated. That is 8,662 B/owner of *existing* effect state, not headroom.
- s1c_attach binds all three distinct histories. s1c_render reads/writes delay then passes wet+dry to the independent reverb, then the master compressor then unconditionally reads/writes the right widen history. Across samples the next read can depend on every old ring. Serial calls in C or sequentially rendering owners do not end state lifetimes. Compact panel delay bypass explicitly retains processing/history; width clock does not stop when mix is zero. Two slots independently hold/release notes and can set all effects on, then silence/sustain one part while the other rings or retriggers. No owner-level deadline or inactive-tail proof permits stealing memory. No user control or runtime tail policy was changed.
- The largest plausible-looking static object, live master delay dly_buf, is exactly 0x21d69 (138,601 B), NOT idle. Engine owns its own 79,200-sample history; controls use T_FX→fxbus_set and the master path runs fxbus_process_st on the combined mix even when both bass owners are S1. The shared bus can be enabled concurrently and accepts independent non-S1 sources. Aliasing is not equivalent.
- E6M9's previously measured 49,380 B reverb/slot by itself is 98,760 B simultaneous. With the already-proven protected-pool excess of 564 B total, preserving existing delay+widen and recycling old reverb only gives 2*2,100+564=4,764 B for new reverb, short **93,996 B**, before any new descriptors. An aggressively impossible bound that also deletes all inherited delay+widen state yields only 17,888 B, still short **80,872 B**. Add 172 B ordinary historical headroom (not proven fungible) and it still cannot close. All original FP32 history calculations are larger; 49,380 B is the specific proven representation size, not an information-theoretic lower bound for all conceivable codings.
- Best independent next question if attempting a different signal structure: retain the measured source-faithful E6M9 arm as oracle and isolate the *late RevSC feedback state*, rather than trying more history aliases or more delay formats. Its eight modulated recurrences with shared junction mix mean an external late convolution is not an exact replacement; test causal age/rate partition or source-ordered nonuniform line coding on both equal-cue short impulse and sustained high-feedback wet scenes, varying room parameters live, before crediting any byte or sound win. No equivalent design at the available RAM is demonstrated.
