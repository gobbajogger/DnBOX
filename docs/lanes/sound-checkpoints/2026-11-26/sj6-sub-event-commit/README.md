# Minimal exact stage-1 crossing hypothesis
This isolates the existing source's Stage-1 control crossing, not a new ADSR or a target transplant. After a genuinely admitted pending Sub owner, the caller passes a positive finite *authentic binary64* source AMP value and actual quantized constructor tick count. Preparation uses one binary64 add and a descending <=0 predicate, exactly at source prep callbacks. A state promotion is emitted once; the caller owns sample/phase/asset promotion and Legato/voice-allocation policy. There is no fixed delay or held-versus-release inference from elapsed use. The standard compact Float32 AMP is **not** eligible as an anchor.

The current source samples (authorized compiled sampler with synthetic marker only) were independently observed at +0x308/+0x320 before each stage-1 tick. probe_anchors.py checks recurrence against all 109 relevant authentic prep observations, while C test.c executes the independent implementation across four cases. Facts: held/midrelease/released/staggered commit after 27/27/27/28 prep callbacks. Promoting the Float32 rounded input to double gives 28/27/27/27; all-float recurrence gives 28/27/28/27. Retargeted or canceled state cannot emit obsolete key after completion; invalid attempts preserve a previously armed state. Existing compact Legato/enable/route tests define the guard boundary and are outside this kernel.

Compile the C fixture with cc -O2 -ffp-contract=off test.c -o test. Build the actual native object using the existing JieLi pi32v2 clang -target pi32v2 -ffp-contract=off -Os -c commit.c. Neither incremental flash after link nor CPU cycles is proved. Standalone compiler measurements do not justify adopting a second full source envelope in firmware.
