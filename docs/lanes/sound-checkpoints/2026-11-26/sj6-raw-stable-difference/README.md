# Stable signed difference-domain check of the Raw shared-source hypothesis

Uses the actual signed matched compact physical input/output and saved
installed dry Raw stereo. Compares (1-z^-L)^4 x to D(z) times the L-point
running sum four times applied to y, divided by hp0. The D(z) is the
existing scoped fixed HP/Crusher/terminal filter denominator. It avoids
unstable DC inversion and retains sample time and amplitude; scores
are in the difference domain, not measured private inputs.

For L=16..64, compact validation matches at around −114 to −118 dBr
during first owner release. Original's implied input differs by −2.2
to −3.0 dBr signed and +7.26 to +10.16 dB level against compact where
the model applies. The implied signal may include other installed
routing or a difference from the assumed whole suffix. Do not apply
a scalar or infer a capture of that private input.
