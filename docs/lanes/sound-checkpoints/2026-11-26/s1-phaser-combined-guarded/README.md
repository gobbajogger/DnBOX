# Synth One bounded Width/Rate phaser control calculations

Applies on the authenticated original-style phaser with the previous exact scalar cache, bounded notch cosine and signed tiny multiplication already applied. Patch only Width exp and Rate coupled coefficient calculations. Physical signal flow/filters, recurrence phase, stage/control ranges, gains, bypass and histories remain unchanged. It is intentionally approximate under measured guards, with exact original double-libm fallback for all inputs outside the domain (including zero/subnormal/NaN parameter angles). It adds no owner data.

Use Float32 as source bounds: Width signed argument [-.375,-minimum-normal], degree-8 exp replacing exp(double); rotation |angle| up to 1/64 and normal, degree-5 sin and degree-4 cos replacing original calls. Original IEEE binary32 angle narrowing happens before the coefficients. Dense 4,194,305-point Float32 grids in each interval measured one ULP max; worst absolute exp error 6.012e-8, sine 4.658e-10, cosine 2.981e-8. Grid is a measurement, not an exhaustive proof. Native same original toolchain -Os -ffp-contract=off; no fast math deployment.

Prior real live traces invalidated Width 214,777 times and Rate 216,711 out of 264,728 active frames in all four real held-edit host patches. Level changed only once. Target leaf bench includes that cadence (390/480 frames), harder continuous width/rate every active frame, steady, plus an out-of-bound exact fallback fixture. Genuine PI32v2 strict emulator timer, same temporary image guard and no NOR changes. 13280 B previous shared tiny baseline ->13472 B active approximation (+192 linked diagnostic bytes). Width/rate 81% fixture 17.47 ->2.089 ms/512; 100% 21.05 ->2.119 ms. Steady 1.956-2.006 ms. Fallback exact stereo PCM and same ~21.8 ms range; not a claimed whole firmware bound. Worst native rate-width comparison null -115.28 dBr, max abs 3.22e-6.

Four actual live/arp connected mono/stereo-cue tests (ARP Octavio/Kiss Me, You Spy!, Pad, Red Minor) including gating, cutover, release and width/rate/feedback/mix edits, same note/cue/state. Compared to all-libm match: whole -100.60...-81.56 dBr and worst tail -91.15 dBr. See reports for signed results. Rebuild source with patch and DNBOX_PH_COEF=1 DNBOX_PH_COS=1 DNBOX_PH_FASTCTL=1. Native baseline = FASTCTL=0 under same other defines, all-libm host drift test = both COS/FASTCTL off. Host donor original note tape and baseline assertions in same-bank.py. Band energy uses correct one-sided Parseval stereo normalization. Never transport private engine PCM or native NOR files.

Direct full all-libm native baseline (DNBOX_PH_COEF=0, COS=0, FASTCTL=0) run on identical fixture: linked 13004 B versus optimized 13472 B, i.e. +468; original phaser owner 192 B versus final 224 B, i.e. +32 from original scalar cache. 77.542-78.107 ms ->2.119 ms sustained two-control update, up to 5.01e-6 positive signed peak and -113.19 dBr worst, without matching output phases or gain by fitting.
