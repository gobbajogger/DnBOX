# Isolated PI32v2 operator evidence
`clang -target pi32v2 -mcpu=r3 -mfprev1 -ffp-contract=off -Os -S target.c -o target.s` (pinned existing project JieLi toolchain). Source mirrors existing hot receiver operation and bounded preparation only. Preparation performs one Float32 multiply per admitted oscillator for the coefficient; the already-existing hot path retains its one conditional carrier multiply. Deliberately excluded unity keeps untouched arithmetic. This is leaf assembly, not native timing, no production full link or fit. C macro is host-only for the actual diagnostic patch.
