# SuperJ6 #109 BIT RATE editor/carrier isolation

**Do not adopt the control/address labels in this historical witness.**
This experiment proves standalone setter and receiver behavior, not which
installed AU parameter reaches the setter. The stronger
[source-mapped installed evidence](../sj6-crusher-source-mapped/README.md)
traces public #108 to the Amount/Decimation path, public #109 to a
metadata-only path, and internal #110 (not a registered public control)
to the Mix path. The earlier direct-call lab bound the laws to the wrong
addresses. Do not expose #109 as a decimation control on this evidence.

Host-only source draft. No firmware default, graph admission, actual DSP
writes, website publication, or native linker claim.

T_MST owner rows 3/4 byte 26 is unsafe: the actual old canonical137 accepts
every possible value because its bound 0 skips opaque master fields. Full
project load copies SOUND137 and default engine master has one public voice.
T_303 logical owner byte 31 (physical rows 8/10 byte 31) is different: old
canonical137 explicitly rejects every nonzero value there. Exhaustive
actual old/new validator probes both owners prove that distinction.
New host-only field uses 0=unassigned, 1..128=stored q+1. Only SuperJ6 INIT
can own it, other owner type rejects nonzero. Other source slot positions,
the old T_MST Crusher bytes, project size and transport packet stay
unchanged. Non-REV137 is rejected by live137 before any control access.
Old typed firmware rejects a new nonzero field rather than play a silent
compatibility remap. Do not promise downgrade with new saved data.

Existing Effect page descriptor and R_SJ6CRUSH dispatch gain slot2 at
original ID109 only under SJ6_RATE_CARRIER_WITNESS. Real Remote row matcher
verifies stock #109 unavailable, new #109 gated and IDs107/108 unchanged.
Uses same typed integer q=0..127 existing expected-old/owner-generation
wire validation, not arbitrary Float32 casts. Actual validated q is
unit_control(q) for physical converter. Legacy unassigned displays UI
position zero but does not attest actual live graph or applied #109, and
an equal-value no-op does not author it. New setter persists only in the
isolated project memory/serialization carrier and Undo bounds-checks before
existing byte restore without calling stock room/Crusher apply for only #109.
Cold preset replacement clears it. No native persistence was performed or
validated on hardware. Existing 7-bit #108 cadence/legacy DSP reads remain
unchanged. No physical suffix association, continuous conversion or
storage redesign. Browser production catalog does not advertise #109.

Reproduce via bash validate.sh /path/to/pinned-warm-tree. It runs actual
canonical137 old/new with bounded untouched source dependencies, exhaustive
256 cells per owner/column, actual packed q/127 converter on the new valid
grid, and exact isolated Remote row matcher. It is not full UI/USB/E2E or
live audio validation. Original inputs not included.
