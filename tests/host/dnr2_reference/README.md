Run `X0X_TEST_JOBS=1 sh tests/run_tests.sh remote-actual-core`. Replaying a cached command refreshes its revision under the source mask, preventing a stale cached revision from hiding external edits. Returned stored-target values do not claim immediate audio application.

CRC is standard reflected IEEE CRC32, initially0xffffffff and finally complemented. Input begins with UTF-8 `dnbox-actual-scalar-host-v1` plus a NUL. Each row contributes eight little-endian uint32 fields: id, kind, target, voice, parameter, bank+1, minimum, maximum, followed by UTF-8 label plus NUL. CRC is compatibility metadata, not authentication. It is independently recomputed from the emitted JSON in producer evidence.
