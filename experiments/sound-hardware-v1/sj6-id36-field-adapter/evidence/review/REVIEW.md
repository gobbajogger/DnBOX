# Independent review of SuperJ6 app ID 36

The frozen adapter is ready for experimental import as a pre-note field binding for independently owned envelopes. It accepts decoded app ID 36 (main-apply position 34) and applies the published normalized attack law to layer 1. Original binary preset decoding, linked envelopes, ID 119 physical behavior, full-preset audio and device qualification remain open.

**Admission and mutation.** The caller must explicitly establish independent envelope ownership. The adapter preflights every field before the physical write, including later link fields 115 and 116. Any nonzero supplied link rejects an attack batch, even if a later duplicate is zero. An omitted link retains its prior raw value. The checked layer setter refreshes layer-1 derived state and leaves layer 2 alone. After a valid commit, all input fields use the existing raw owner, including ID 119 and externally owned metadata. With the documented serialized access and immutable input array, preflight covers all errors of the pinned raw store. See `sj6_preset_fields.c` lines 16–60 and `dnbx_core.c` lines 230–243 and 407–428.

**Measured behavior.** The saved suite applied five normalized values and checked the published physical targets within 0.00001 seconds. Across 10,240 stereo frames, the decoded-field path exactly matched the direct physical candidate. The audible layer-2 channel matched the untreated control. The rejection cases compared the entire part before and after. The raw-store baseline and wrong-layer mutant both retained an 8 ms attack at raw zero, where 2 ms was expected. The linear mutant yielded 4.00150013 seconds at one quarter, where 0.160199791 seconds was expected. Saved executable exits were 1, 0, 1 and 1 for raw-only, candidate, wrong-layer and linear-law respectively. See `tests/test_id36.c` lines 11–61 and 63–105 and `evidence/focused-01`. The separate source-free physical amplitude fixture contains 5,120 previously recorded endpoints from two cases.

**Historical runner.** In `verify.py` line 36, Python optimization removes the mutation-anchor uniqueness check. Lines 26–28 resolve the output path before creating its directory, so an ancestor symlink can redirect a fresh run. Neither issue changes the saved four executions. The canonical maintainer plans explicit anchor validation and rejection of symlink ancestors while preserving this historical runner. This review covers the frozen scratch package. The proposed canonical revision requires its own provenance.

I verified all 22 manifest payloads by size and SHA-256, all seven pinned repository inputs and the five local source hashes recorded by the run. I inspected the implementation, tests and saved streams. I did not rerun the compiler or render audio.
