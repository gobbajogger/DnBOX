# Native SuperJ6 factory path link gap

The 12-run native lab receipt actually exercises wet Synth One plus Chicago. The lab packages do not contain the complete SuperJ6 factory stereo effect path. The SuperJ6 bank/ARP receipts are host results; they do not prove a native fit, realtime or app audio match.

With the exact same six Part Sound flags plus only X0X_SUPERJ6_FACTORY=1, the actual JieLi linker rejects both models: Elite is 1,108 B over app XIP, Pro 1,100 B over. In the failing Pro map the stereo renderer and factory receiver are present. No linker limit or reserve was reduced, no package was published, and this does not qualify a separate original-delay variant.

The exact encoded 909 cymbals do not fit a simple reuse of the existing project LZ at a smaller size; all three get slightly larger even with optimal parsing in that format. It would save 944 B on Chicago coefficient pack A and 641 B on E before decoder cost, but promoting both to writable memory would consume 20,696 B and erase nearly the entire newly recovered pool. Neither route was accepted. Prefer measured XIP-only elimination or a format that retains existing RAM and exact hot read behavior before timing the actual SuperJ6 stereo path.
