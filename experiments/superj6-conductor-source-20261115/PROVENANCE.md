# Provenance and preservation scope

This package contains newly authored control/reference code and tests derived from bounded static inspection of an authorized SuperJ6 reference, not copied app executable instructions or an original SDK. Reference identity: SuperJ6 version0.999.8/build9; inspected AU SHA256 `a5243e50bda6bd44f463c6e63ea3137802142f55f3c1ea25a5a6e046acba81a1`. The original app, recordings and user preset banks are not included or required to run these tests. This is not an official AudioKit/SuperJ6 implementation, an app-source license claim, or a claim of sound identity.

Control ordering/default metadata and source-width/lifecycle laws are retained as explicit data and executable own tests. Human-readable source addresses in the metadata are provenance facts, not an executable original-code payload. Earlier own reference implementations included for comparison are clearly test-only. The package has no dependency on newer tuning experiments or unqualified engine compositions.

The source transport is based on the independently reviewed Conductor ACK-fix source manifest `c0aa80867cb2c043be847508f4ae0afa29cf48bc9700de138a74a1cd6d129268`. Production code, Python reference code, data and tests are byte-identical to that source. Private baseline/history documents were omitted and replaced with these current public-facing documents. The host runner changes only source-manifest/result filenames for this transport; its verification, commands and failure handling are unchanged. `SOURCE-MANIFEST.json` enumerates the complete plaintext closure and hashes.

This is bounded source preservation, not firmware integration or runtime admission. Reproduction runs own host implementations against synthetic/literal-law references. They do not replay original recorded audio or establish the full preset/engine/FX/transport graph. Review of this package cannot replace the exact combined-source numerical, storage, real-time, heavy-workload, audio or device qualification required before integration.
